## My Current Research

My current work focuses on **risk-guided parent-lineage growth control for dynamic 3D Gaussian SLAM**.

The main idea is to analyze Gaussian growth from a lifecycle and lineage perspective, and suppress risky parent lineages before clone/split operations in order to reduce redundant Gaussian proliferation in dynamic regions.
